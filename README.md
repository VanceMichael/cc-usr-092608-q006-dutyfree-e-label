# 离岛免税电子标签与通关版本链

管理免税化妆品电子标签、通关资料、库存去向和消费者信息版本。

## 参与方与事实

主要参与方包括免税经营企业、仓库人员、海关监管人员、药品监管人员、消费者。领域资料记录以下已经确认的事实：

- 海南离岛免税化妆品电子标签政策已规模化应用
- 二维码可展示商品成分、原产地和通关信息
- 电子标签用于改善小规格商品中文信息可读性并提升监管效率

## 业务约束

- 标签发布版本
- 批次实物对应
- 通关单证
- 消费者公开视图
- 补发失效
- 件数守恒

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/label_context.py` 负责读取和校验这些资料。

## 监管服务

`src/elabel/` 实现电子标签监管服务，把商品型号、进口批次、成分声明、原产地证明、中文说明、通关单证、仓位与标签载体连成逐件可核对的关系：

- `models.py` — 领域模型：批次、资料、草案、标签版本、逐件、载体、库存流水、出区核放、召回
- `service.py` — `LabelService` 应用服务：
  - 标签草案经资料审核与签发两个职责分离后生成不可回改的正式版本，签发人只能引用已确认资料
  - 二维码始终解析到批次当前正式版本；消费者扫码只见中文成分、原产地、中文说明与通关摘要，配方附件永不公开
  - 分装、部分放行、换仓、退运、销毁时逐件实物与标签身份一起移动，件数守恒
  - 破损补发的新码接续旧码历史，旧载体立即失效
  - 抽检异常或成分更正只冻结关联批次；召回逐件定位已出区商品的销售状态与通知进度
  - 海关核放锁定实际核验的标签版本；幂等键保证重复提交不重复扣减库存，矛盾单证停在人工处理
  - `trace_serial` 供监管人员按商品序列查看审批依据、码值替换、库存去向和任一时点的消费者视图
- `store.py` — 整体 JSON 快照持久化；`LabelService.restore` 重启恢复后由 `recovery_queue` 优先给出未完成出区与召回通知

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
