# 离岛免税电子标签与通关版本链

管理免税化妆品电子标签、通关资料、库存去向和消费者信息版本。

## 参与方与事实

主要参与方包括免税经营企业、仓库人员、海关监管人员、药品监管人员、消费者。领域资料记录以下已经确认的事实：

- 海南离岛免税化妆品电子标签政策已规模化应用
- 二维码可展示商品成分、原产地和通关信息
- 电子标签用于改善小规格商品中文信息可读性并提升监管效率

## 业务约束

- 标签发布版本
- 批次实物对应
- 通关单证
- 消费者公开视图
- 补发失效
- 件数守恒

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/label_context.py` 负责读取和校验这些资料。

## 电子标签监管服务

`src/event_store.py` 提供 JSONL 追加事件日志（逐行落盘、启动回放），
`src/regulatory_service.py` 在其上实现逐件可核对的监管关系：

- 商品型号、进口批次、四类资料（成分声明/原产地证明/中文说明/通关单证）、
  标签草案与正式版本
- 资料审核与标签签发两职分离，签发人只能引用已确认资料
- 二维码始终指向一个不可变正式版本，消费者扫码只见白名单公开内容，
  企业配方附件不公开
- 分装、部分放行、换仓、退运、销毁逐件件数守恒；破损补发新码接续旧码历史
  并立即停用旧载体
- 抽检异常与成分更正只冻结关联批次；出区后召回可定位销售状态与通知进度
- 海关核放锁定实际核验的标签版本，重复提交幂等不重复扣库存，矛盾单证停
  人工处理
- 重启后优先恢复未完成出区核放与召回通知
- 按商品序列查询审批依据、码值替换、库存去向与各时点消费者可见中文信息

规则细节见 `docs/service-rules.md`。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
